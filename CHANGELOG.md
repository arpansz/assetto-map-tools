# Changelog

## 0.1.0 - 2026-09-27

Initial public starter release.

### Added
- `acvalidate obj` command.
- OBJ geometry sanity checks.
- MTL and texture-reference validation.
- Conservative naming warnings.
- Text and JSON report modes.
- Exit codes suitable for CI.
- Minimal Blender source-scene validator.
- Pytest coverage and GitHub Actions workflow.
